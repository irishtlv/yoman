# היומן שלי

אפליקציית יומן אישית: מסך "היום" עם 4 בלוקים, לוח, רשימת קניות, "לא לשכוח", מסך אלמה עם נקודות וחיסכון, וספר מתכונים.
עובדת מול Google Calendar, ושומרת את הסימונים והמתכונים ב-Firebase. אפשר להוסיף אותה למסך הבית באייפון.

- `index.html`, `main.js` – המסכים
- `platform.js` – כניסה עם Google, Google Calendar, Firebase, ו-AI אופציונלי
- `config.js` – ההגדרות (מזהה Google, Firebase, כתובת AI)
- `setup/` – כללי אבטחה ל-Firestore וקוד השרת הקטן ל-AI

הנתונים עצמם לא נמצאים במאגר הזה. הם נשמרים בחשבון שלך ב-Firebase ונגישים רק לך אחרי כניסה.
